# Сторінка в Chrome Web Store — українською

Назва й короткий підсумок беруться з пакета (англійською). Опис нижче можна додати як переклад
для мови «Українська» на вкладці «Сторінка продукту».

## Опис

🔥 Додавайте людей зі своїх листів у Gmail до списків розсилки SendPulse в один клік.

Якщо ви працюєте з SendPulse і листуєтеся в Gmail, більше не потрібно копіювати адреси вручну чи вивантажувати CSV. Відкрийте лист — і всі учасники листування вже в панелі SendPulse праворуч, готові до додавання в обраний список.

✨ Можливості

• Показує всіх учасників відкритого листування (відправник, одержувачі, копія), крім вас
• Показує, в яких списках SendPulse кожна людина вже є
• Позначає тих, кого ще немає в SendPulse; пропускає розсилки noreply та сповіщення
• Заповнює ім'я та прізвище із заголовка листа або підпису
• Знаходить у підписі телефон, компанію, посаду, сайт і профіль LinkedIn
• Усе можна перевірити й відредагувати перед збереженням
• Додає всіх позначених людей в обраний список одним кліком
• Автоматично розкладає поля по змінних списку (firstName, Name, Company, Phone…) і запам'ятовує вибір для кожного списку
• «Find» відкриває пошук людини в LinkedIn у новій вкладці

🚀 Як почати

1. Встановіть розширення й відкрийте Gmail.
2. Відкрийте будь-який лист — у правій бічній панелі з'явиться іконка SendPulse.
3. Підключіть акаунт прямо в панелі за допомогою API-ключа SendPulse
   (SendPulse → Налаштування → API → Ключі API → Створити ключ)
   або за допомогою ID та Secret (Налаштування → API → Облікові дані).
4. Оберіть список розсилки й натисніть «Add to SendPulse».

🔒 Конфіденційність

• API-ключ зберігається лише в сховищі розширення у вашому браузері й ніколи не потрапляє на сторінку Gmail.
• Ваші дані йдуть тільки в офіційний API SendPulse (api.sendpulse.com). Жодних наших серверів посередині, аналітики чи реклами. Бібліотека інтеграції з Gmail (InboxSDK) може надсилати своєму розробнику анонімні технічні звіти про помилки.
• Вміст листів читається локально — лише щоб знайти імена й контакти у відкритому листуванні.
• Коли ви відкриваєте лист, адреси учасників перевіряються у вашому акаунті SendPulse, щоб показати їхній статус. Імена й дані зберігаються в SendPulse тільки після натискання «Add».
