## Опис

🔥 Простий спосіб імпортувати контакти з Gmail у списки SendPulse — безкоштовно

Якщо ви працюєте з SendPulse і Gmail, не витрачайте час на ручне створення списків чи копіювання адрес у SendPulse.
Знайомтеся: SendPulse Gmail Extension — відкрийте лист і додайте його учасників у списки SendPulse одним кліком.

🆕 Нове у версії 2.0

Повністю перебудовано для сучасного Chrome (Manifest V3):
• Панель SendPulse прямо в бічній панелі Gmail для кожного відкритого листа
• Видно, в яких списках SendPulse людина вже є, — жодних дублікатів
• Ім'я, телефон, компанія, посада, сайт і LinkedIn — автоматично з підпису листа
• Вхід за API-ключем SendPulse за кілька секунд
• Новий охайний дизайн у стилі Gmail

🤖 Як це працює?

1. Додайте розширення SendPulse у Chrome.
2. Увійдіть в акаунт SendPulse, відкрийте Налаштування → API → Ключі API і створіть ключ
   (або скористайтеся ID та Secret з Налаштування → API → Облікові дані).
3. Відкрийте Gmail і будь-який лист — праворуч у бічній панелі з'явиться іконка SendPulse.
4. Вставте ключ у панель і натисніть «Підключити».
5. Панель покаже всіх учасників листування: відправника, одержувачів і копію. Ті, кого ще немає в SendPulse, уже позначені.
6. Перевірте ім'я, прізвище та дані, знайдені в підписі; за потреби відредагуйте їх.
7. Оберіть список для імпорту й натисніть «Додати в SendPulse».

🎉 Готово! Усі обрані люди вже у вашому списку SendPulse.

✨ Що ще вміє розширення

• Показує статус кожного учасника в SendPulse: в яких списках він є або «Ще немає в SendPulse»
• Бере ім'я із заголовка листа, а якщо там лише адреса — з підпису
• Знаходить у підписі телефон, компанію, посаду, сайт і профіль LinkedIn (підписи українською, англійською, іспанською, німецькою, португальською, польською, турецькою й французькою)
• Кнопка «Знайти» відкриває пошук людини в LinkedIn у новій вкладці
• Автоматично розкладає поля по змінних списку (firstName, Name, Company, Phone…) і запам'ятовує вибір для кожного списку
• Пропускає розсилки noreply та сповіщення, перетворює телефони в міжнародний формат
• Налаштування відкриваються прямо в панелі Gmail або у спливному вікні по кліку на іконку розширення
• Інтерфейс 8 мовами, зокрема українською

🔒 Конфіденційність

• API-ключ зберігається лише в сховищі розширення у вашому браузері й ніколи не потрапляє на сторінку Gmail.
• Ваші дані йдуть тільки в офіційний API SendPulse (api.sendpulse.com). Жодних наших серверів посередині, аналітики чи реклами. Бібліотека інтеграції з Gmail (InboxSDK) може надсилати своєму розробнику анонімні технічні звіти про помилки.
• Вміст листів читається локально — лише щоб знайти імена й контакти у відкритому листуванні.
• Коли ви відкриваєте лист, адреси учасників перевіряються у вашому акаунті SendPulse, щоб показати їхній статус. Імена й дані зберігаються в SendPulse тільки після натискання «Додати».
• Жодного доступу до Facebook: старий пошук імен через Facebook прибрано.
