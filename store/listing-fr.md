## Description

🔥 Un moyen simple et gratuit d’importer les contacts de votre boîte Gmail dans vos listes SendPulse

Si vous utilisez SendPulse et Gmail, ne perdez plus de temps à créer des listes à la main ou à copier-coller des adresses dans SendPulse.
Découvrez SendPulse Gmail Extension : ouvrez un e-mail et ajoutez ses participants à vos listes SendPulse en un clic.

🆕 Nouveautés de la version 2.0

Entièrement repensée pour le Chrome actuel (Manifest V3) :
• Un panneau SendPulse dans la barre latérale de Gmail pour chaque e-mail ouvert
• Voyez dans quelles listes SendPulse chaque personne figure déjà — fini les doublons
• Nom, téléphone, entreprise, poste, site web et LinkedIn récupérés dans la signature de l’e-mail
• Connexion avec une clé API SendPulse en quelques secondes
• Un nouveau design épuré, assorti à Gmail

🤖 Comment ça marche ?

1. Ajoutez l’extension SendPulse à Chrome.
2. Connectez-vous à SendPulse, ouvrez Paramètres → API → Clés API et créez une clé
   (ou utilisez l’ID et le Secret dans Paramètres → API → Identifiants).
3. Ouvrez Gmail et n’importe quel e-mail : l’icône SendPulse apparaît dans la barre latérale droite.
4. Collez la clé dans le panneau et cliquez sur « Connecter ».
5. Le panneau affiche tous les participants de la conversation : expéditeur, destinataires et copie. Les personnes qui ne sont pas encore dans SendPulse sont déjà sélectionnées.
6. Vérifiez le prénom, le nom et les informations trouvées dans la signature ; modifiez-les si besoin.
7. Choisissez la liste de destination et cliquez sur « Ajouter à SendPulse ».

🎉 Et voilà ! Toutes les personnes choisies sont maintenant dans votre liste SendPulse.

✨ Ce qu’elle sait faire d’autre

• Affiche le statut SendPulse de chaque participant : les listes où il figure ou « Pas encore dans SendPulse »
• Reprend le nom de l’en-tête de l’e-mail, ou de la signature quand l’en-tête n’affiche que l’adresse
• Trouve téléphone, entreprise, poste, site web et profil LinkedIn dans la signature de l’expéditeur (signatures en français, anglais, espagnol, allemand, portugais, polonais, turc et ukrainien)
• Le bouton « Chercher » ouvre la recherche de personnes LinkedIn dans un nouvel onglet
• Associe automatiquement les champs aux variables de votre liste (firstName, Name, Company, Phone…) et mémorise votre choix pour chaque liste
• Ignore les expéditeurs noreply et les notifications, convertit les numéros au format international
• Les paramètres s’ouvrent directement dans le panneau Gmail ou dans une fenêtre depuis l’icône de l’extension
• Interface en 8 langues, dont le français

🔒 Confidentialité

• Votre clé API est stockée uniquement dans l’espace de stockage de l’extension de votre navigateur et n’atteint jamais la page Gmail.
• Vos données vont uniquement vers l’API officielle de SendPulse (api.sendpulse.com). Aucun serveur à nous entre les deux, ni statistiques ni publicité. La bibliothèque d’intégration Gmail (InboxSDK) peut envoyer des rapports d’erreurs techniques anonymes à son développeur.
• Le contenu des e-mails est lu localement, uniquement pour trouver les noms et coordonnées dans la conversation ouverte.
• À l’ouverture d’un e-mail, les adresses des participants sont recherchées dans votre compte SendPulse pour afficher leur statut. Les noms et informations ne sont enregistrés dans SendPulse que lorsque vous cliquez sur « Ajouter à SendPulse ».
• Plus d’accès à Facebook : l’ancienne recherche de noms via Facebook a été supprimée.
